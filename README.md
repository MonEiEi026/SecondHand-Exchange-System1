# ระบบแอปพลิเคชันแลกเปลี่ยนและส่งต่อสิ่งของมือสอง

## สมาชิกในกลุ่ม

- น.ส.กมลวรรณ แก้วเจิมจิ (สนุ๊กเกอร์)
- นายธนากร บานเย็น (ต้น)
- นายศิลาชัย บูรณะสิน (ม่อน)
- นายณัฐภัทร หอมละออ (มิน)

## รายละเอียดโครงการ

ระบบแอปพลิเคชันสำหรับแลกเปลี่ยนและส่งต่อสิ่งของมือสอง
ภายในมหาวิทยาลัย

## ฟังก์ชันหลัก

- สมัครสมาชิกและเข้าสู่ระบบ
- เพิ่มประกาศสินค้า
- ค้นหาสินค้าตามชื่อและหมวดหมู่
- ติดต่อผู้ขายผ่านแชต
- แก้ไขและลบประกาศ
- เปลี่ยนสถานะเป็นขายแล้วหรือแจกแล้ว
